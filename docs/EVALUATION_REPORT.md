# SUFE Guide 离线回归评测

## 评测范围

- 评测集：65 条人工整理问题，其中 55 条可回答、10 条应拒答；
- 资料来源：仓库内 122 份资料和 1038 个证据块；
- 覆盖主题：学籍教务、转专业、校外学习、奖助评优、校园服务、就业手续、推免升学、研究生事务和范围外问题；
- 运行方式：`uv run --no-sync python -m app.evaluate`；
- 注意：这是固定资料快照上的离线回归评测，不是线上用户满意度、并发性能或真实大模型能力评测。

## 检索版本

| 版本 | 主要变化 | Hit@1 | Hit@5 | MRR | 拒答准确率 | 关键词覆盖率 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| V1 | 基础词法匹配 | 74.55% | 89.09% | 0.8091 | 84.62% | 87.69% |
| V2 | 降低“怎么、哪里、申请”等意图词影响 | 74.55% | 90.91% | 0.8142 | 81.54% | 89.23% |
| V3 | 标题、关键词和正文分字段加权 | 80.00% | 92.73% | 0.8452 | 96.92% | 92.31% |
| V4 | 增加证据块、词项稀有度、查询覆盖率、资料状态及同义词 | 85.45% | 100.00% | 0.9082 | 100.00% | 100.00% |

采用 V4。它在固定集上没有相对 V3 的回退案例，并改善了缓考、退学、考试成绩比例、毕业证遗失和结业换证等需要深入条款的问题。V2 曾让部分问题退化，说明只删除意图词并不能保证排序更好。

V4 的单次检索平均耗时约 65 ms、P95 约 97 ms（本机离线串行测量）。证据片段匹配提高了可解释性，也增加了 CPU 开销；这些数字不能外推为服务器并发性能。

## Prompt 版本

- V1：通用校园问答指令；
- V2：要求先检索、引用资料、无证据拒答；
- V3：增加工具选择、日期和适用对象检查，以及“结论—依据—限制/下一步”的回答结构。

Prompt 版本由代码管理，远程模型请求会写入所选 system prompt；自动测试验证了 V3 和 Tool Calling 协议。当前没有使用真实大模型批量评测，因此不宣称 Prompt V3 带来某个百分比的回答质量提升。

## Hybrid V5

V5 使用 V4 词法分数与 `Qwen/Qwen3-Embedding-4B` 向量相似度混合。默认关闭，以保证离线和 CI 可运行。配置个人硅基流动 Key 并生成索引后，可执行：

```powershell
uv run --no-sync python -m app.evaluate --include-hybrid
```

只有实际运行后，才能决定 Hybrid 是否优于 V4；不能因为使用 embedding 就预设效果一定提升。
